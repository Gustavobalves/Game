# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/9332062c-f45c-4e64-b432-e28afc7d575a

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`


## Modelo 3D detalhado

O carro inicial carrega um modelo esportivo 3D detalhado (GLB) no showroom e durante a corrida. O arquivo é hospedado no repositório do autor e está sob licença CC0 1.0. É necessário acesso à internet para baixar o modelo na primeira utilização; se o carregamento falhar, o jogo mantém o modelo procedural original como alternativa. O modelo é um esportivo realista genérico, não uma réplica oficial licenciada de Porsche/Toyota/Nissan.

Fonte do modelo: https://github.com/JaronKBragg7337/spectral-gt-rs
Licença: CC0 1.0 Universal.
